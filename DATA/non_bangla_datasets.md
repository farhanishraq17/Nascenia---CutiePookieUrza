# Missing Non-Bangla Medical Datasets

The following non-Bangla (English / International) medical datasets checked during analysis are **NOT** currently present in the project workspace:

1. **MedMCQA**
   - **URL:** https://huggingface.co/datasets/openlifescienceai/medmcqa
   - **Platform:** Hugging Face
   - **Language:** English
   - **Description:** Multiple-choice question answering dataset derived from Indian medical entrance examinations (AIIMS / NEET-PG).

2. **BigBio MedQA**
   - **URL:** https://huggingface.co/datasets/bigbio/med_qa
   - **Platform:** Hugging Face
   - **Language:** English
   - **Description:** Biomedical QA dataset standard adapter from the BigBio project.

3. **MedQA Reading Comprehension (med-rcq)**
   - **URL:** https://huggingface.co/med-rcq/MedQA
   - **Platform:** Hugging Face
   - **Language:** English
   - **Description:** Reading comprehension question-answering dataset based on MedQA.

4. **MediQAl**
   - **URL:** https://huggingface.co/datasets/ANR-MALADES/MediQAl
   - **Platform:** Hugging Face
   - **Language:** French / English
   - **Description:** Clinical QA benchmark dataset by ANR MALADES.
