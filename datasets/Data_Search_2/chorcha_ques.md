## ⚠️ Important: Question text could not be extracted

The individual **question wording is not publicly available** on this page. It is
gated behind account login **and** paid batch enrollment. As an anonymous visitor,
only the *structure* of the question bank (year categories and question counts) is
exposed — the question content itself is withheld.

Evidence gathered during scraping:

| Check | Result |
|-------|--------|
| Rendered page (browser) | Shows **"No questions found"** for every year, anonymous |
| Embedded page data (Next.js RSC) | `questions` field **masked** as `"AAAA…"` (1 `A` = 1 question) |
| Content visibility flag | `visibility: "batch_only_archive"` (enrolled batch students only) |
| Question-serving API (`/api/`, `/api-v1/`) | **Disallowed by `robots.txt`** — not scraped |
| `sitemap.xml` / sub-sitemaps | **Empty** — no public question URLs |

No question text was fabricated, and no authentication or `robots.txt` restriction
was bypassed. The section below therefore lists the **publicly visible taxonomy only**,
not question content.
